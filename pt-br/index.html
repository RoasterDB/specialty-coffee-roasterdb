Resumo

Um catálogo estruturado de 8.000+ produtos de cafés especiais de 280+ torrefações artesanais selecionadas em 20+ países. O RoasterDB lê a loja on-line ao vivo de cada torrefação e mapeia suas notas sensoriais de forma determinística para os nós hierárquicos padrão da Roda de Sabores da SCA, com uma URL de origem em cada registro para que qualquer dado possa ser verificado novamente.

Perguntas frequentes sobre o dataset e a taxonomia

O que é o dataset de cafés especiais RoasterDB?

O RoasterDB é um banco de dados estruturado e factual com mais de 8.000 cafés especiais de 280+ torrefações artesanais em 20+ países. Cada registro inclui atributos padronizados como país de origem, altitude (m), método de processamento, variedades e notas sensoriais mapeadas diretamente para a Roda de Sabores da SCA.

Como as notas sensoriais são mapeadas para a Roda de Sabores da SCA?

O RoasterDB converte descrições poéticas ou não estruturadas das torrefações (como "Grandma's peach cobbler" ou "bright clementine acidity") em caminhos hierárquicos estritos de 3 níveis da Roda de Sabores da SCA (por exemplo: Fruity > Other Fruit > Peach). Isso permite filtragem semântica precisa e extração de features para machine learning.

Quais formatos de banco de dados estão incluídos no download?

O pacote de download inclui um arquivo de banco de dados SQLite relacional normalizado (.db) com tabelas separadas para torrefações, cafés e vínculos com nós de sabor, além de exportações limpas em CSV e JSON para importação direta no pandas, no R, em scripts Python ou em aplicações web.
