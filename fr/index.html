Résumé

Un catalogue structuré de 8 000+ produits de café de spécialité issus de 280+ torréfacteurs artisanaux sélectionnés dans 20+ pays. RoasterDB lit la boutique en ligne de chaque torréfacteur et associe de manière déterministe ses notes de dégustation aux nœuds hiérarchiques standard de la roue des arômes SCA — avec une URL source sur chaque enregistrement, afin que chaque fait puisse être revérifié.

§ 04 · Questions fréquentes

Base de connaissances structurée

FAQ sur le jeu de données & la taxonomie

Qu'est-ce que le jeu de données RoasterDB sur le café de spécialité ?

RoasterDB est une base de données structurée et factuelle contenant plus de 8 000 cafés de spécialité issus de 280+ torréfacteurs artisanaux dans 20+ pays. Chaque entrée comprend des attributs standardisés tels que le pays d'origine, l'altitude (m), la méthode de traitement, les variétés et les notes de dégustation directement associées à la roue des arômes SCA.

Comment les notes de dégustation sont-elles associées à la roue des arômes SCA ?

RoasterDB convertit les descriptions poétiques ou non structurées des torréfacteurs (comme "Grandma's peach cobbler" ou "bright clementine acidity") en chemins hiérarchiques stricts à 3 niveaux de la roue des arômes SCA (par exemple : Fruity > Other Fruit > Peach). Cela permet un filtrage sémantique précis et l'extraction de caractéristiques pour l'apprentissage automatique.

Quels formats de base de données le téléchargement comprend-il ?

Le package téléchargeable comprend un fichier de base de données SQLite relationnelle normalisée (.db) avec des tables distinctes pour les torréfacteurs, les grains de café et les liens vers les nœuds aromatiques, ainsi que des exports CSV et JSON propres pour une importation directe dans pandas, R, des scripts Python ou des applications web.
